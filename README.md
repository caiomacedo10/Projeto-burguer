# Loja de Hambúrgueres Interativa 

## Descrição  
Desenvolvi uma Hamburgueria Digital onde os usuários podem explorar e filtrar diferentes tipos de hambúrgueres, incluindo opções veganas, visualizar o valor total dos pedidos e muito mais! O projeto foca em uma interface intuitiva e responsiva, proporcionando uma experiência fluida e agradável.

## Tecnologias Utilizadas  

- HTML5 para estruturação semântica  

- CSS3 para estilização moderna e responsiva  

- JavaScript para manipulação dinâmica dos dados e interatividade

## Funcionalidades  

- Filtro interativo para exibir apenas lanches veganos ou todos os itens  

- Cálculo automático do valor total do pedido em tempo real  

- Lista dinâmica que exibe todos os hambúrgueres disponíveis com detalhes  

- Interface responsiva que funciona bem em dispositivos móveis e desktops
